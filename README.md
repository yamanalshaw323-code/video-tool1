# VideoTool - تحميل فيديو + استخراج موسيقى

## طريقة الحصول على ملف APK فعلي (مجانًا، من غير ما تنزّل حاجة على جهازك)

1. اعمل حساب مجاني على github.com لو معندكش
2. اعمل Repository جديد (New repository) وسمّيه مثلًا VideoTool
3. ارفع كل الملفات والمجلدات اللي جوه الملف المضغوط ده داخل الـ repo (اسحب وافلت عبر واجهة GitHub في صفحة الـ repo، أو استخدم Git)
4. روح لتاب "Actions" في أعلى صفحة الـ repo، هتلاقي الـ workflow اسمه "Build APK" بدأ يشتغل تلقائيًا
5. استنى لحد ما يخلص (علامة صح خضراء ✅)، بعدين ادخل على الـ run اللي خلص، هتلاقي في الأسفل قسم "Artifacts" فيه ملف اسمه app-debug-apk
6. نزّل الملف ده، فكّه هتلاقي جواه app-debug.apk — ده ملف APK حقيقي جاهز للتثبيت على أي جهاز أندرويد (لازم تفعّل "تثبيت من مصادر غير معروفة" في إعدادات الجهاز)

## أو: ابنيه بنفسك على جهازك
افتح المشروع بـ Android Studio واعمل Run، أو من قايمة Build اختار Build APK(s).
